# Nag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Nag, a menu-less macOS app that opens a Title/Subtitle/Message window, posts a native notification, and quits.

**Architecture:** A SwiftUI `App` with one `Window` scene acts as the composition root. It injects a protocol-backed `NotificationService` (over `UNUserNotificationCenter`) and a "finish" (quit) action into a `@MainActor @Observable` `ComposeViewModel`. An `AppDelegate` handles activation, foreground notification presentation, and quitting when the window closes. The Xcode project is generated from `project.yml` by XcodeGen.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI, AppKit, UserNotifications, Swift Testing, XcodeGen, Xcode 27 / macOS 27.

**Spec:** `docs/superpowers/specs/2026-10-01-nag-design.md`

## Global Constraints

- Deployment target: macOS 27.0. `SWIFT_VERSION` is `6.0` (Swift 6 language mode, strict concurrency).
- Bundle ID: `com.codefriar.nag`; test bundle ID: `com.codefriar.nag.tests`.
- Signing: ad-hoc (`CODE_SIGN_IDENTITY = "-"`), with no development team and no hardened runtime.
- `LSUIElement = YES`: no Dock icon and no app-switcher entry.
- `Nag.xcodeproj/` and `build/` are gitignored. `project.yml` is the source of truth.
- Tests use Swift Testing (`import Testing`), not XCTest assertions.
- Window title: "New Nag". Field labels: "Title", "Subtitle", "Message". Buttons: "Send", "Cancel", "Open Settings".
- Copy, verbatim:
  - Denied error: `Notifications are off for Nag.`
  - Not-persistent hint: `Nags will disappear on their own. Set Nag to “Alerts” to keep them on screen.`
- Settings URL: `x-apple.systempreferences:com.apple.Notifications-Settings.extension`
- Icon: SF Symbol `checkmark.seal.text.page`, white, on an orange gradient `#FF9F0A` → `#FF6B00`.
- Run every command from the repo root, `/Users/kpoorman/src/nag`.

## Review Focus

1. **Closing the window with the red button or ⌘W.** The app must quit. Otherwise an invisible, Dock-less process keeps running. (Task 3: `applicationShouldTerminateAfterLastWindowClosed` plus a manual check.)
2. **Quitting immediately after posting.** The notification must still appear. The app is in the foreground at post time, so `willPresent` must answer before the process exits. (Task 3: `finish` hides the window, then terminates after 500 ms, plus a manual check.)
3. **Pressing Return twice quickly.** Exactly one notification should be posted. (Task 2: the `secondSendWhileInFlightIsIgnored` test.)
4. **Title with leading or trailing newlines, or a whitespace-only Subtitle or Message pasted in.** These should be trimmed or left out, never posted as blank lines. (Task 2: trimming and nil-optional tests.)
5. **Retrying after a failed send.** The old error should clear and a successful retry should quit. (Task 2: the `retryClearsPreviousError` test.)

```swift
import Foundation
import UserNotifications

enum AlertStyle: Equatable, Sendable {
    case none, banner, alert
}

enum AuthorizationState: Equatable, Sendable {
    case denied
    case authorized(alertStyle: AlertStyle)
}

enum NotificationError: Error, Equatable {
    case notAuthorized
}

protocol NotificationPosting: Sendable {
    /// Requests permission on first use, then reports the current state.
    func authorizationState() async -> AuthorizationState
    func post(title: String, subtitle: String?, body: String?) async throws
}

struct NotificationService: NotificationPosting {
    func authorizationState() async -> AuthorizationState {
        let center = UNUserNotificationCenter.current()
        var settings = await center.notificationSettings()
        if settings.authorizationStatus == .notDetermined {
            _ = try? await center.requestAuthorization(options: [.alert, .sound])
            settings = await center.notificationSettings()
        }
        switch settings.authorizationStatus {
        case .denied, .notDetermined:
            return .denied
        default:
            return .authorized(alertStyle: AlertStyle(settings.alertStyle))
        }
    }

    func post(title: String, subtitle: String?, body: String?) async throws {
        guard case .authorized = await authorizationState() else {
            throw NotificationError.notAuthorized
        }
        let content = UNMutableNotificationContent()
        content.title = title
        if let subtitle { content.subtitle = subtitle }
        if let body { content.body = body }
        content.sound = .default
        // A unique ID per request makes nags stack instead of replacing each other.
        let request = UNNotificationRequest(
            identifier: UUID().uuidString,
            content: content,
            trigger: nil
        )
        try await UNUserNotificationCenter.current().add(request)
    }
}

private extension AlertStyle {
    init(_ style: UNAlertStyle) {
        switch style {
        case .alert: self = .alert
        case .banner: self = .banner
        default: self = .none
        }
    }
}
```

- [ ] **Step 3: Create `NagTests/FakeNotifications.swift`**

```swift
import Foundation

/// Test double for `NotificationPosting`. It records every post and can
/// throw a configured error. With `holdPosts`, each post suspends until
/// `releasePost()` is called, so tests can observe the in-flight state.
actor FakeNotifications: NotificationPosting {
    struct Post: Equatable, Sendable {
        let title: String
        let subtitle: String?
        let body: String?
    }

    private(set) var posts: [Post] = []
    private let state: AuthorizationState
    private var postError: (any Error)?
    private let holdPosts: Bool
    private var postStarted = false
    private var startWaiters: [CheckedContinuation<Void, Never>] = []
    private var release: CheckedContinuation<Void, Never>?

    init(
        state: AuthorizationState = .authorized(alertStyle: .alert),
        postError: (any Error)? = nil,
        holdPosts: Bool = false
    ) {
        self.state = state
        self.postError = postError
        self.holdPosts = holdPosts
    }

    func setPostError(_ error: (any Error)?) {
        postError = error
    }

    func authorizationState() async -> AuthorizationState {
        state
    }

    func post(title: String, subtitle: String?, body: String?) async throws {
        posts.append(Post(title: title, subtitle: subtitle, body: body))
        if holdPosts {
            postStarted = true
            startWaiters.forEach { $0.resume() }
            startWaiters.removeAll()
            await withCheckedContinuation { release = $0 }
        }
        if let postError { throw postError }
    }

    func waitUntilPostStarted() async {
        guard !postStarted else { return }
        await withCheckedContinuation { startWaiters.append($0) }
    }

    func releasePost() {
        release?.resume()
        release = nil
    }
}
```

```swift
import AppKit
import Observation

@MainActor
@Observable
final class ComposeViewModel {
    enum Hint: Equatable, Sendable {
        case deniedPermission
        case notPersistent
    }

    static let notificationSettingsURL = URL(
        string: "x-apple.systempreferences:com.apple.Notifications-Settings.extension"
    )!

    var title = ""
    var subtitle = ""
    var body = ""
    private(set) var hint: Hint?
    private(set) var errorMessage: String?
    private(set) var isSending = false

    var canSend: Bool { !Self.trimmed(title).isEmpty }

    private let notifications: any NotificationPosting
    private let finish: @MainActor () -> Void
    private let openURL: @MainActor (URL) -> Void

    init(
        notifications: any NotificationPosting,
        finish: @escaping @MainActor () -> Void,
        openURL: @escaping @MainActor (URL) -> Void = { _ = NSWorkspace.shared.open($0) }
    ) {
        self.notifications = notifications
        self.finish = finish
        self.openURL = openURL
    }

    func refreshStatus() async {
        switch await notifications.authorizationState() {
        case .denied:
            hint = .deniedPermission
        case .authorized(alertStyle: .alert):
            hint = nil
        case .authorized:
            hint = .notPersistent
        }
    }

    func send() async {
        guard canSend, !isSending else { return }
        isSending = true
        defer { isSending = false }
        errorMessage = nil
        do {
            try await notifications.post(
                title: Self.trimmed(title),
                subtitle: Self.nilIfBlank(subtitle),
                body: Self.nilIfBlank(body)
            )
            finish()
        } catch NotificationError.notAuthorized {
            errorMessage = "Notifications are off for Nag."
            hint = .deniedPermission
        } catch {
            errorMessage = error.localizedDescription
        }
    }

    func cancel() {
        finish()
    }

    func openNotificationSettings() {
        openURL(Self.notificationSettingsURL)
    }

    private static func trimmed(_ text: String) -> String {
        text.trimmingCharacters(in: .whitespacesAndNewlines)
    }

    private static func nilIfBlank(_ text: String) -> String? {
        let value = trimmed(text)
        return value.isEmpty ? nil : value
    }
}
```

import SwiftUI

struct ComposeView: View {
    @Bindable var viewModel: ComposeViewModel
    @FocusState private var titleFocused: Bool

    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            if let bannerText {
                banner(bannerText)
            }
            Form {
                TextField("Title", text: $viewModel.title)
                    .focused($titleFocused)
                TextField("Subtitle", text: $viewModel.subtitle)
                TextField("Message", text: $viewModel.body, axis: .vertical)
                    .lineLimit(3...8)
            }
            HStack {
                Spacer()
                Button("Cancel", role: .cancel) { viewModel.cancel() }
                    .keyboardShortcut(.cancelAction)
                Button("Send") { Task { await viewModel.send() } }
                    .keyboardShortcut(.defaultAction)
                    .disabled(!viewModel.canSend || viewModel.isSending)
            }
        }
        .padding(20)
        .frame(width: 420)
        .task {
            titleFocused = true
            await viewModel.refreshStatus()
        }
    }

    private var bannerText: String? {
        if let errorMessage = viewModel.errorMessage { return errorMessage }
        switch viewModel.hint {
        case .deniedPermission:
            return "Notifications are off for Nag."
        case .notPersistent:
            return "Nags will disappear on their own. Set Nag to “Alerts” to keep them on screen."
        case nil:
            return nil
        }
    }

    private func banner(_ text: String) -> some View {
        HStack(alignment: .firstTextBaseline, spacing: 8) {
            Image(systemName: "exclamationmark.triangle.fill")
                .foregroundStyle(.orange)
            Text(text)
                .fixedSize(horizontal: false, vertical: true)
            Spacer(minLength: 8)
            if viewModel.hint != nil {
                Button("Open Settings") { viewModel.openNotificationSettings() }
            }
        }
        .padding(10)
        .background(.orange.opacity(0.12), in: RoundedRectangle(cornerRadius: 8))
    }
}

@main

@MainActor
final class AppDelegate: NSObject, NSApplicationDelegate, UNUserNotificationCenterDelegate {
    func applicationWillFinishLaunching(_ notification: Notification) {
        // Must be set before launch completes so foreground posts are presented.
        UNUserNotificationCenter.current().delegate = self
    }

    func applicationDidFinishLaunching(_ notification: Notification) {
        // LSUIElement apps don't come to the front on their own.
        NSApp.activate()
    }

    func applicationShouldTerminateAfterLastWindowClosed(_ sender: NSApplication) -> Bool {
        true
    }

    nonisolated func userNotificationCenter(
        _ center: UNUserNotificationCenter,
        willPresent notification: UNNotification
    ) async -> UNNotificationPresentationOptions {
        [.banner, .list, .sound]
    }

    /// Hides the window immediately, then quits after a short delay so the
    /// system can finish presenting the notification just posted.
    static func finish() {
        // orderOut (not close) so the last-window-closed rule doesn't quit early.
        NSApp.windows.forEach { $0.orderOut(nil) }
        Task { @MainActor in
            try? await Task.sleep(for: .milliseconds(500))
            NSApp.terminate(nil)
        }
    }
}

```swift
// Renders the SF Symbol `checkmark.seal.text.page` into Nag's AppIcon set.
// Usage (from the repo root): swift scripts/make-icon.swift
import AppKit

let symbolName = "checkmark.seal.text.page"
let canvas: CGFloat = 1024
let topColor = NSColor(srgbRed: 1.0, green: 0x9F / 255.0, blue: 0x0A / 255.0, alpha: 1)
let bottomColor = NSColor(srgbRed: 1.0, green: 0x6B / 255.0, blue: 0x00 / 255.0, alpha: 1)

let repoRoot = URL(fileURLWithPath: #filePath)
    .deletingLastPathComponent()
    .deletingLastPathComponent()
let catalog = repoRoot.appending(path: "Nag/Assets.xcassets")
let iconSet = catalog.appending(path: "AppIcon.appiconset")

func render(pixels: Int) -> Data {
    let rep = NSBitmapImageRep(
        bitmapDataPlanes: nil, pixelsWide: pixels, pixelsHigh: pixels,
        bitsPerSample: 8, samplesPerPixel: 4, hasAlpha: true, isPlanar: false,
        colorSpaceName: .deviceRGB, bytesPerRow: 0, bitsPerPixel: 0
    )!
    // Draw in a 1024-point coordinate space regardless of the output pixel size.
    rep.size = NSSize(width: canvas, height: canvas)

    NSGraphicsContext.saveGraphicsState()
    NSGraphicsContext.current = NSGraphicsContext(bitmapImageRep: rep)

    // macOS icon grid: an 824-point body centered on a 1024-point canvas.
    let bodyRect = NSRect(x: 100, y: 100, width: 824, height: 824)
    let bodyPath = NSBezierPath(roundedRect: bodyRect, xRadius: 185, yRadius: 185)

    NSGraphicsContext.saveGraphicsState()
    let shadow = NSShadow()
    shadow.shadowColor = NSColor.black.withAlphaComponent(0.3)
    shadow.shadowBlurRadius = 20
    shadow.shadowOffset = NSSize(width: 0, height: -10)
    shadow.set()
    bottomColor.setFill()
    bodyPath.fill()
    NSGraphicsContext.restoreGraphicsState()

    NSGradient(starting: topColor, ending: bottomColor)!.draw(in: bodyPath, angle: -90)

    let config = NSImage.SymbolConfiguration(pointSize: 420, weight: .regular)
        .applying(NSImage.SymbolConfiguration(paletteColors: [.white]))
    guard let symbol = NSImage(systemSymbolName: symbolName, accessibilityDescription: nil)?
        .withSymbolConfiguration(config) else {
        fatalError("SF Symbol \(symbolName) is not available on this system")
    }
    let scale = (canvas * 0.55) / max(symbol.size.width, symbol.size.height)
    let size = NSSize(width: symbol.size.width * scale, height: symbol.size.height * scale)
    symbol.draw(in: NSRect(
        x: (canvas - size.width) / 2,
        y: (canvas - size.height) / 2,
        width: size.width,
        height: size.height
    ))

    NSGraphicsContext.restoreGraphicsState()
    return rep.representation(using: .png, properties: [:])!
}

let fileManager = FileManager.default
try fileManager.createDirectory(at: iconSet, withIntermediateDirectories: true)

var images: [[String: String]] = []
for points in [16, 32, 128, 256, 512] {
    for scale in [1, 2] {
        let filename = scale == 1
            ? "icon_\(points)x\(points).png"
            : "icon_\(points)x\(points)@2x.png"
        try render(pixels: points * scale).write(to: iconSet.appending(path: filename))
        images.append([
            "filename": filename,
            "idiom": "mac",
            "scale": "\(scale)x",
            "size": "\(points)x\(points)",
        ])
    }
}

let info = ["author": "xcode", "version": 1] as [String: Any]
let encoder = { (object: Any) in
    try JSONSerialization.data(withJSONObject: object, options: [.prettyPrinted, .sortedKeys])
}
try encoder(["images": images, "info": info]).write(to: iconSet.appending(path: "Contents.json"))
try encoder(["info": info]).write(to: catalog.appending(path: "Contents.json"))
print("Wrote \(images.count) icons to \(iconSet.path)")
```

````markdown
# Nag

A tiny macOS app for posting native notifications that stay on screen.
Launch it, type a title (plus an optional subtitle and message), and press Return.
The notification is posted and Nag quits.

## Requirements

- macOS 27, Xcode 27
- [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`

## Install

```sh
make install   # builds Release and copies Nag.app to /Applications
```

Other targets: `make test`, `make build`, `make icon` (regenerate the app icon), `make clean`.

## First run

1. Launch Nag and click **Allow** when macOS asks about notifications.
2. Open **System Settings → Notifications → Nag** and set the alert style to **Alerts**.
   Nag shows a hint with an **Open Settings** button until you do.
   With "Banners", notifications disappear after a few seconds.

## Using it

- **Return** sends, and **Esc** cancels. Title is required.
- In the Message field, **Option-Return** inserts a newline.
- Clicking a delivered nag opens a fresh Nag window.

## Alfred

Create a workflow with a keyword trigger connected to a **Launch Apps** action that targets `Nag.app`.
You can also use a Terminal Command or Run Script action with `open -a Nag`.

## Icon

The icon is the SF Symbol `checkmark.seal.text.page`. Apple's SF Symbols license does not allow symbols in app icons.
That's acceptable here only because Nag is personal and not distributed. Replace the icon before any public release.
````
